# Neo Game Studio MCP Bridge

جسر MCP بسيط مبني على Node.js لتوفير أدوات حالة المشروع وأوامر التطوير.

## المتطلبات
- Node.js 20 أو أحدث.
- إصدارات مباشرة مثبتة في `package.json` لضمان تثبيت متوقع.

## التشغيل
```bash
npm install
npm start
```

يستمع الخادم إلى `PORT` (الافتراضي 3000). يعرض المسار `/` رسالة حالة نصية، ويقدم نقطة MCP على `/mcp`.

## فحوص
```bash
node --check server.mjs
```

الأوامر الحالية تؤكد استقبال الطلب وتعيد بيانات حالة تجريبية؛ لا تدّعي أنها تنفذ فعليًا بناء الألعاب أو تعديل ملفات المشاريع.
